Como o LUME deverá funcionar

A ideia é apresentar conteúdos curtos e atividades progressivas, com uma interface fácil de entender.

  1. Escolha suas preferências.

    Defina o tamanho e o tipo de letra mais confortáveis para você.

  2. Entre ou experimente como hóspede.

    O acesso de hóspede permite conhecer a interface sem criar uma conta.

  3. Conheça os conteúdos.

    As trilhas deverão apresentar explicações simples e atividades organizadas por etapas.

  4. Pratique com orientação.

    A proposta prevê dicas visuais e explicações para ajudar quando uma atividade parecer difícil.

  5. Avance no seu ritmo.

    Futuramente, o progresso poderá ser salvo para facilitar a retomada dos estudos.

Sobre esta versão

Por enquanto, esta é uma interface demonstrativa. Não há servidor nem sincronização entre dispositivos. Os dados de exemplo ficam no armazenamento local do navegador.
